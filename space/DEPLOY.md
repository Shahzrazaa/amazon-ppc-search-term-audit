# Deploying the demo as a free Hugging Face Space

1. Create a new Space (SDK: Gradio, hardware: free CPU basic).
2. Upload: `space/README.md` (as `README.md`), `space/requirements.txt` (as `requirements.txt`),
   `app.py`, `ppc_audit.py` and `sample/search_term_report_sample.csv` (keep the `sample/` folder).
3. The Space builds automatically. Add its URL to the main README under "Browser demo".
